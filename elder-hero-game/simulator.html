วงจรต่อสาย

ปุ่มทุกปุ่มและแผ่นรองนั่งต่อระหว่างขาของ micro:bit กับ GND ส่วนไฟ LED ต่อผ่านตัวต้านทาน 220 โอห์ม ขา P8 ถึง P15 ต้องใช้บอร์ดขยายขา

ภาษาที่กล่องคุยกับแอป

ส่งเป็นข้อความสั้น ๆ ทีละบรรทัดผ่านสาย USB ความเร็ว 115200

BTN:R / Y / Gกดปุ่มแดง เหลือง เขียว SOSกดปุ่มขอความช่วยเหลือ SEAT:1 / 0มีคนนั่ง / ลุกจากแผ่นรอง OK / NOแอปบอกว่าตอบถูก / ผิด LED:R / Y / G / OFFแอปสั่งเปิดไฟสี GOเริ่มจับเวลาลุกนั่ง NUM:1–5แสดงจำนวนครั้งบนจอไฟ CLEARปิดเสียงเตือน SOS
