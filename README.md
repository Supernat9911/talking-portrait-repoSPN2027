# สตูดิโอใบหน้าพูดได้ (Talking Portrait)

ต้นแบบอวาตาร์พูดได้ที่ทำงานในเบราว์เซอร์ทั้งหมด อัปโหลดรูปใบหน้าและคลิปเสียง แล้วใบหน้าจะขยับปาก กะพริบตา และขยับศีรษะตามเสียง

## ความสามารถ
- อัปโหลดรูปได้หลายรูป (ลากมาวางหรือคลิกเลือก) แล้วสลับรูปจากคลังได้
- วางจุดตา 2 จุดและกลางปาก 1 จุด (เบราว์เซอร์ที่มี `FaceDetector` จะหาจุดให้อัตโนมัติ)
- อัปโหลดคลิปเสียงได้หลายไฟล์ หรือกดอัดเสียงจากไมโครโฟน (ใบหน้าขยับตามขณะอัด) แสดงรูปคลื่นเสียง และระบุสำเนียงของแต่ละคลิป
- ลิปซิงก์จากความดังและย่านความถี่ formant (อา / อี / อู / ปิด)
- กะพริบตาแบบสุ่ม ส่ายศีรษะ พยักหน้า และยกคิ้วตามจังหวะเสียง
- อ่านข้อความด้วยเสียงสังเคราะห์ของเครื่อง (ต้องติดตั้งเสียงภาษาไทยในระบบปฏิบัติการ)
- ตัวละครจาก Character Sheet: ตัวละคร HUSOC มี 2 ท่า (หน้าตรง และโบกมือ) และใช้ภาพปากจริงจากชีต 6 แบบ คือ ปิด A E I O U ระบบเลือกรูปปากจากเสียงแล้วค่อยๆ ผสมภาพเปลี่ยนไป แถบรูปปากใต้ภาพจะไฮไลต์รูปปากที่ใช้อยู่ และกดเพื่อดูทีละแบบได้

## สร้างตัวละครจากรูปของคุณ (ในหน้าเว็บ)
กดปุ่ม **เริ่ม** ในขั้นที่ 1 แล้วหน้าเว็บจะพาทำทีละขั้น ขั้นแรกคือเลือกรูปคนใหม่ ซึ่งพูดได้ทันทีแบบเบื้องต้น จบด้วยตัวละครที่มีรูปปากครบ

1. ขั้นที่ 1 เลือกสไตล์ แล้วกด **คัดลอกพรอมต์**
2. เปิด AI สร้างภาพ เช่น ChatGPT หรือ Gemini แนบรูปใบหน้า แล้ววางพรอมต์ AI จะสร้างภาพตาราง 3×3 ตามลำดับนี้

   | | | |
   |---|---|---|
   | 1 ปากปิด | 2 A · อา | 3 E · เอ |
   | 4 I · อี | 5 O · โอ | 6 U · อู |
   | 7 หลับตา | 8 โบกมือ | 9 ไหว้ |

3. กด **นำเข้า Character Sheet** แล้วเลือกภาพที่ได้
4. วางจุดตาและปากบนช่องแรก แล้วกด **เสร็จสิ้น**

หลังกดเสร็จสิ้น ระบบจะทำงานในเบราว์เซอร์ทั้งหมด ไม่ส่งภาพออกไปไหน
- หั่นภาพเป็น 9 ช่อง
- เทียบใบหน้าส่วนที่ไม่เปลี่ยน เพื่อหาตำแหน่งและขนาดของแต่ละช่อง
- ตัดเฉพาะบริเวณปาก (ช่อง 2–6) และตา (ช่อง 7) มาซ้อนบนช่องแรก
- สร้างท่าทางเพิ่มอีก 2 ท่าจากช่อง 8 และ 9

ถ้า AI สร้างภาพที่ขนาดหรือตำแหน่งหน้าในแต่ละช่องต่างกันมาก หน้าเว็บจะเตือน ให้สร้างภาพใหม่

## เพิ่มตัวละครจาก Character Sheet (สคริปต์)
ไฟล์ต้นฉบับอยู่ที่ `characters/husoc/sheet.jpg` สคริปต์ `tools/build_character.py` จะทำงานดังนี้
1. ตัดภาพแต่ละท่า (ปากปิด) และหัวรูปปาก A E I O U ออกจากชีต
2. จัดหัวแต่ละรูปปากให้ทับตรงกับท่าหลัก โดยเทียบช่วงคิ้ว ตา และจมูก
3. ตัดเฉพาะบริเวณปาก แล้วทำขอบให้จางลง
4. หาตำแหน่งตาดำให้อัตโนมัติ
5. รวมทุกอย่างเป็นไฟล์ `characters/husoc.js` (ฝังภาพเป็น data URI จึงเปิด `index.html` จากเครื่องได้เลย)

```
pip install opencv-python-headless numpy
python3 tools/build_character.py
```

ถ้าจะใช้ชีตใหม่ ให้แก้พิกัดในตัวแปร `HUSOC` ในสคริปต์ ได้แก่ กรอบของแต่ละท่า, ตำแหน่งกึ่งกลางของหัวแต่ละรูปปาก, และค่า `eye_scale` ที่ใช้ขยายเปลือกตาตอนกะพริบให้พอดีกับตาการ์ตูนตาโต แล้วเพิ่ม `<script src="characters/ชื่อ.js">` ใน `index.html`

ท่ามองด้านข้างใช้กับรูปปากหน้าตรงไม่ได้ จึงไม่ได้นำมาใช้

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร หรือเปิด GitHub Pages ของ repo นี้

ไฟล์ที่อัปโหลดอยู่ในหน้าเว็บเท่านั้น ไม่ถูกส่งไปที่เซิร์ฟเวอร์ใด

## ข้อจำกัด
- การขยับใช้ WebGL บิดภาพนิ่ง ยังไม่ได้ใช้โมเดล AI สร้างภาพใบหน้าใหม่
- ยังโคลนเสียงหรือสำเนียงไม่ได้ ระบบจะเล่นคลิปที่อัปโหลดตามเดิม ถ้าจะให้พูดข้อความใหม่ด้วยเสียงนั้น ต้องมีเซิร์ฟเวอร์ GPU (ดูแบบระบบในหน้าเว็บ)

## การใช้ใบหน้าและเสียงของผู้อื่น
ใช้เฉพาะรูปและเสียงของตัวเอง หรือของคนที่ให้ความยินยอมแล้วเท่านั้น
