# สตูดิโอใบหน้าพูดได้ (Talking Portrait)

ต้นแบบอวาตาร์พูดได้ที่ทำงานในเบราว์เซอร์ทั้งหมด อัปโหลดรูปใบหน้าและคลิปเสียง แล้วใบหน้าจะขยับปาก กะพริบตา และขยับศีรษะตามเสียง

## ความสามารถ
- อัปโหลดรูปได้หลายรูป (ลากมาวางหรือคลิกเลือก) แล้วสลับรูปจากคลังได้
- วางจุดตา 2 จุดและกลางปาก 1 จุด (เบราว์เซอร์ที่มี `FaceDetector` จะหาจุดให้อัตโนมัติ)
- อัปโหลดคลิปเสียงได้หลายไฟล์ แสดงรูปคลื่นเสียง และระบุสำเนียงของแต่ละคลิป
- ลิปซิงก์จากความดังและย่านความถี่ formant (อา / อี / อู / ปิด)
- กะพริบตาแบบสุ่ม ส่ายศีรษะ พยักหน้า และยกคิ้วตามจังหวะเสียง
- อ่านข้อความด้วยเสียงสังเคราะห์ของเครื่อง (ต้องติดตั้งเสียงภาษาไทยในระบบปฏิบัติการ)

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร หรือเปิด GitHub Pages ของ repo นี้

ไฟล์ที่อัปโหลดอยู่ในหน้าเว็บเท่านั้น ไม่ถูกส่งไปที่เซิร์ฟเวอร์ใด

## ข้อจำกัด
- การขยับใช้ WebGL บิดภาพนิ่ง ยังไม่ได้ใช้โมเดล AI สร้างภาพใบหน้าใหม่
- ยังโคลนเสียงหรือสำเนียงไม่ได้ ระบบจะเล่นคลิปที่อัปโหลดตามเดิม ถ้าจะให้พูดข้อความใหม่ด้วยเสียงนั้น ต้องมีเซิร์ฟเวอร์ GPU (ดูแบบระบบในหน้าเว็บ)

## สตูดิโอเสียง (`voice-studio.html`)
ไทม์ไลน์เสียง 4 แทร็กในหน้าเดียว ทำงานในเบราว์เซอร์ทั้งหมด
- **เสียงพากย์**: อัดเสียงจากไมค์ อัปโหลดไฟล์ หรือพิมพ์ให้เครื่องอ่าน
- **เสียงคนอื่น**: เลือกเสียงจากคลัง (ผู้บรรยายสารคดี ป้าแม่ค้า เด็กน้อย ยักษ์ หุ่นยนต์ ฯลฯ) หรือพิมพ์บอกลักษณะเสียงแล้วระบบแปลงเสียงอัดให้ (ปรับระดับเสียง โทน ความเร็ว ก้อง โทรศัพท์ เสียงสั่น)
- **เพลง**: พิมพ์บอกแบบเพลง เช่น “สดใส” “ตื่นเต้น” “พื้นหลัง” “เศร้า” “ลึกลับ” แล้วแต่งเพลงประกอบด้วยเครื่องสังเคราะห์
- **เอฟเฟกต์**: พิมพ์หรือเลือกเสียง เช่น คลิก วูบ ปรบมือ เคาะประตู ฝนตก ระเบิด (19 เสียง)
- ลากคลิปบนไทม์ไลน์ ปรับความดัง ปิดเสียงทีละแทร็ก แล้วบันทึกเป็นไฟล์ WAV

ข้อจำกัด: ยังโคลนเสียงคนจริงหรือแปลภาษาด้วย AI ไม่ได้ ต้องต่อบริการ AI ภายนอก คลิปที่ให้เครื่องอ่านเล่นในไทม์ไลน์ได้ แต่ไม่รวมอยู่ในไฟล์ WAV

## การใช้ใบหน้าและเสียงของผู้อื่น
ใช้เฉพาะรูปและเสียงของตัวเอง หรือของคนที่ให้ความยินยอมแล้วเท่านั้น
